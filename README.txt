Biznes Ayol — многостраничный демонстрационный сайт на HTML, CSS и JavaScript.

Страницы:
index.html — главная;
courses.html — курсы, поиск и фильтрация;
business-plan.html — 3 примера бизнес-планов и скачивание собственного плана в TXT;
tools.html — калькуляторы прибыли, бюджета и аннуитетного кредитного платежа;
digital.html — цифровые навыки и шаблон публикации;
consultations.html — информация о банковских консультациях и форма подготовки обращения;
about.html — информация о платформе.

Запуск:
1. Распакуйте архив.
2. Откройте папку в Visual Studio Code.
3. Откройте index.html в браузере или запустите через Live Server.
4. Не перемещайте HTML-файлы отдельно от папок css и js.

Важно: это учебный шаблон, не официальный сайт банка. Формы не отправляют данные на сервер. Для реального запуска нужны официальные контакты и условия банка, серверная обработка заявок, политика конфиденциальности, проверка безопасности и согласование с банком. Цифры в примерах условные; кредитный калькулятор ориентировочный.
